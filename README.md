# Mystery Name Draw

A privacy-first platform for organizing gift exchanges, book swaps, game-night grabs, office celebrations, and other anonymous group events.

Unlike traditional Secret Santa tools, Mystery Name Draw is designed so that organizers can manage an event without seeing who was assigned to whom.

## Why Mystery Name Draw?

Most gift-exchange tools focus on holiday events. Mystery Name Draw supports year-round exchanges:

- Holiday gift exchanges
- Book club swaps
- Office celebrations
- Teacher appreciation events
- Board game communities
- Hobby groups
- Custom exchange events

## Core Principles

### Participant Privacy
Participants register themselves.

### Organizer Transparency
Organizers can see registration counts and event status, but not individual assignments.

### Flexible Events
Not limited to Secret Santa. Create any exchange event for any group.

## Planned Features
